TSCPP Help Page
This page lists the commands you can use in the TSCPP terminal.
[Commands]
help - open this help page from the main terminal.
page2 - also opens this help page from the main terminal.
info/information/about - open the About TSCPP page.
errorcodes/errors - open the Error Codes page.
status - open the Status page.
theme grey / grey - set the terminal theme to grey.
theme blue / blue - set the terminal theme to blue.
theme green / green - set the terminal theme to green.
theme red / red - set the terminal theme to red.
connect - unlock the terminal after timeout.
lore - opens a page with the lore of the scps and foundation.
rules - open the Rules page.
discord - open the Discord info page.
home - return to the main page from here.
commands - show the commands section again.
[Notes]
Use lowercase or uppercase commands; both work the same.
If you get an invalid command, type errorcodes for the error reference page.
For server-specific help, open the Rules or Discord pages.
