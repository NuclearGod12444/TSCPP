TSCPP Error Codes
E001 - "INVALID_COMMAND" - The command entered was not recognized.
E002 - "PAGE_NOT_FOUND" - The requested page does not exist yet.
E003 - "MISSING_PARAMETER" - A required command parameter is missing.
E004 - "ACCESS_DENIED" - You do not have permission to use that page or command.
E005 - "SERVER_OFFLINE" - The Discord server or service is temporarily unavailable.
E006 - "BAD_INPUT" - The input format is incorrect, try a different command style.
E007 - "UNKNOWN_ERROR" - An unexpected error occurred; try again later.
E008 - "CODE_ERROR" - An error has occurred in the code that processed the command and was disabled due to detected malfunction. (something not working right or is missing and causing issues)
TSCPP Status Codes
ONLINE - No issues detected.
WARNING - A slight issue was detected, but still operational.
CRITICAL - A significant issue was detected, and functionality may be impacted.
ERROR - Complete failure.
For more details, ask a staff member or check the help page.
