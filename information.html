About TSCPP
TSCPP is short for The Secure Contain Protect Project, an SCP Foundation community.
This page explains what TSCPP is about and where to find help.
TSCPP is a community about SCPs and SCP roleplaying, the Discord server is where the main stuff happens, there are many channels with specific purposes as a part of the foundation roleplay.
If you see an error code in the site, open the error codes page to get the meaning.
